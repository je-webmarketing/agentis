# Local Geist fonts

Official variable WOFF2 files from [vercel/geist-font](https://github.com/vercel/geist-font/tree/742b08235ce818c6c464c1323087ea38a1241ff1), pinned to commit `742b08235ce818c6c464c1323087ea38a1241ff1`.

- `Geist-Variable.woff2`: `fonts/Geist/webfonts/Geist[wght].woff2`
- `GeistMono-Variable.woff2`: `fonts/GeistMono/webfonts/GeistMono[wght].woff2`

Both files are unmodified, normal-style variable fonts with weights 100–900. They are loaded by `next/font/local`; no Google Fonts request is needed at build time. The SIL Open Font License is included in `OFL.txt`.
